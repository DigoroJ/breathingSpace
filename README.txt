# Breathing Space Resort Website

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` in a browser.

## Before publishing
1. Replace the sample Unsplash images with real resort images.
2. Replace the video placeholders with `<video>` elements or embedded videos.
3. Add the real phone number and email address.
4. Replace the `#` Facebook, Instagram and TikTok links with the real profiles.
5. Connect the inquiry form to a backend/form service. The current JavaScript validates the form and displays a confirmation, but it does not send email.

The site is built with plain HTML, CSS and vanilla JavaScript and is responsive on mobile, tablet and desktop.
